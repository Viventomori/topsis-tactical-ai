# simulation — імітаційне моделювання та експерименти (Python)

Незалежна від Unity реалізація бойового середовища та методу, на якій отримано всі експериментальні результати статті.

| Файл | Призначення | У статті |
|---|---|---|
| `battle_sim.py` | Середовище (поле [0; 100], укриття, бази), агенти, контролери, TOPSIS | — |
| `example_topsis.py` | Числовий приклад і чутливість до кількості ворогів | Табл. 4–8 |
| `review_experiments.py` | Парна схема (200 seed × 2 сторони = 400 боїв), ДІ, тести, абляція, чутливість до ваг | Табл. 9, 10, 12, 13 |
| `env_sensitivity.py` | Чутливість до параметрів середовища | Табл. 11 |
| `figure_dynamics.py` | Динаміка частки стратегій за тіками | Рис. 1 |
| `results/` | Збережені результати (JSON) і рисунок | — |

```bash
cd simulation
pip install -r requirements.txt
python example_topsis.py        # табл. 4–8
python review_experiments.py    # табл. 9, 10, 12, 13 (~8 хв)
python env_sensitivity.py       # табл. 11 (~3 хв)
python figure_dynamics.py       # рис. 1
```

Перевірено на Python 3.11.15, SciPy 1.17.1. Усі серії використовують фіксовані seed, тому результати відтворювані.
